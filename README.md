# Монтаж Reels с телефона через Claude Code

Шаблон для монтажа вертикальных видео (говорящая голова) **только с телефона**: субтитры, акценты, текст за головой, стеклянные плашки, наезды камеры, звуковые эффекты и обложка. Компьютер не нужен.

## Что понадобится
- Телефон с приложением **Claude** (подписка Pro или выше) и браузером.
- Аккаунт на **github.com** (бесплатно).
- Google Drive — для видео больше 25 МБ.

## Настройка (один раз, ~10 минут)
1. **Копия шаблона.** На этой странице: «Use this template» → «Create a new repository» → имя, например `montazh` → **Private** → «Create repository».
2. **Подключить GitHub к Claude.** Приложение Claude → меню → **Code** → «+ Новая сессия» → «Добавить репозиторий» → «Репозитории» → «+ Подключить еще» → в GitHub выбрать «Only select repositories» → свой `montazh` → «Save» → «Вернуться в приложение Claude».
3. **Среда.** В новой сессии нажать «Default» → «+ Создать среду»:
   - Имя: `Монтаж`
   - Доступ к сети: **Полный** (нужен для скачивания моделей и видео по ссылке)
   - Скрипт настройки — вставить:
     ```
     apt-get update -qq && apt-get install -y -qq ffmpeg; python3 .claude/skills/montazh-pro/scripts/pro.py setup || true
     ```
   - «Создать среду».

## Каждый монтаж
1. Загрузить видео:
   - до 25 МБ — github.com → свой репозиторий → папка `Исходники` → «Add file» → «Upload files» → «Commit changes»;
   - больше — в Google Drive, «Поделиться» → «Все, у кого есть ссылка», скопировать ссылку.
2. Claude → Code → «+ Новая сессия» → репозиторий `montazh`, среда `Монтаж`.
3. Написать: **«Смонтируй видео»** (+ ссылку на Drive, если видео там).
4. Ответить на вопросы (стиль, цвет, текст видео со *звёздочками* на главных словах).
5. Посмотреть **эскизы** по ссылке → написать «ок» или правки.
6. Получить ссылку на готовое видео → скачать → сохранить в галерею → публиковать.

## Папки
- `Исходники/` — исходные видео
- `Эскизы/` — раскадровки перед рендером
- `Готовые/` — финальные видео `_v1, _v2…` и обложки `.png`
- `правки.md` — ваши личные предпочтения; Claude дописывает их сам и учитывает в следующих видео.
