# Монтаж Reels с телефона (облачный Claude Code)

Пользователь работает **только с телефона**. Компьютера у него нет. Все объяснения — простыми словами, по шагам, с учётом мобильного приложения Claude и мобильного сайта GitHub.

## Монтаж
Для любого монтажа, эскизов, рендера, обложки и правок используй скил **montazh-pro** (`.claude/skills/montazh-pro/SKILL.md`) и выполняй его порядок без пропусков: вопросы → эскизы → одобрение → рендер → проверка → сдача. Личные правки пользователя — в `правки.md` (если файл есть, прочитай его первым).

## Начало каждой сессии
1. `git pull` — подтянуть видео, которые пользователь загрузил через GitHub.
2. `python3 .claude/skills/montazh-pro/scripts/pro.py check` — если чего-то нет, `… setup` (2–4 мин) и `apt-get install -y ffmpeg` при необходимости.
3. Посмотри, какие видео лежат в `Исходники/`. Если пусто — объясни, как загрузить (ниже).

## Как видео попадает сюда
- **GitHub (до 25 МБ)**: в репозитории на github.com → папка `Исходники` → «Add file» → «Upload files» → выбрать видео → «Commit changes». Потом скажи мне «загрузил», я сделаю `git pull`.
- **Видео больше 25 МБ** (обычно так): загрузить в Google Drive → «Поделиться» → «Все, у кого есть ссылка» → скопировать ссылку и прислать в чат. Скачай:
  `pip install -q gdown && gdown --fuzzy "<ссылка>" -O "Исходники/<имя>.mp4"`
- **Dropbox**: в ссылке заменить `dl=0` на `dl=1`, скачать `curl -L -o "Исходники/<имя>.mp4" "<ссылка>"`.
- Имя файла — латиницей или кириллицей без пробелов и спецсимволов (переименуй при скачивании).

## Как отдать результат на телефон
Облачная сессия не может прислать файл напрямую — только через GitHub.
После эскизов, рендера и обложки:
```bash
git add Эскизы Готовые; [ -f правки.md ] && git add правки.md
git commit -m "<что сделано>" && git push
```
Затем дай **прямую ссылку** на файл:
`https://github.com/<owner>/<repo>/blob/<ветка>/<путь, закодированный в URL>` (owner/repo/ветка — из `git remote -v` и `git branch --show-current`; кириллицу и пробелы в пути кодируй через urllib.parse.quote).

И короткую инструкцию:
- **Эскизы/обложка (картинка)**: открыть ссылку → картинка видна сразу. Сохранить: нажать на картинку и удерживать → «Сохранить в Фото».
- **Видео**: открыть ссылку → кнопка «⋯» (или «Download raw file» / иконка скачивания) → файл скачается → на iPhone: «Файлы» → «Загрузки» → открыть видео → «Поделиться» → «Сохранить видео». На Android: «Загрузки» → видео уже в галерее.

## Правила работы в облаке
- Рендер всегда с `--max-mb 90` (GitHub не принимает файлы > 100 МБ) и **в фоне** (run_in_background), чтобы сессия не оборвалась; длительность рендера ~1–3 мин на минуту видео.
- Никогда не коммить `.montazh/` (рабочие файлы) и исходники больше 90 МБ. Исходник, скачанный по ссылке, не коммить вообще.
- Не создавай pull request'ы и новые ветки — пушь в текущую ветку.
- Если push не прошёл из-за прав — объясни, что в настройках среды нужен доступ к репозиторию, и не теряй готовый файл.
- Пиши по-русски (или на языке пользователя), коротко. Технические детали (ffmpeg, json) пользователю не объясняй без вопроса.
